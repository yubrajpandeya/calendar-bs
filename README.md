# News Bihani Calendar

News Bihani's first-party Nepali calendar for
[`calendar.newsbihani.com`](https://calendar.newsbihani.com).

## Features

- Responsive Bikram Sambat monthly calendar for BS 2000–2090
- Nepal-time “today” view with AD dates, Saturdays, holidays, and festivals
- Two-way BS/AD date conversion
- Verified BS 2083 holiday, festival, regional, and observance data
- First-party JSON endpoints for calendar months, conversions, and holidays
- Self-hosted fonts and assets; no runtime calendar or typography API

## Commands

```bash
npm install
npm run dev
npm run lint
npm test
```

The API reference is available at `/api-docs`.
